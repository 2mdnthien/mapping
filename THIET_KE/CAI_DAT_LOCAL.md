# Cài trên máy

Đã thay bằng **`HUONG_DAN_LOCAL.md`** ở thư mục gốc của repo. File đó là phiếu giao việc để Claude trên máy tự cài, gồm 8 bước, mỗi bước có chốt. Phần cuối file ghi những việc anh Thiên phải tự làm bằng tay.

SHA1 của các file cài nằm trong **`SHA1SUMS.txt`**, do `tao_ban_phat_hanh.py` sinh ra. Script `kiem_sha1.py` dùng file này để đối chiếu.
